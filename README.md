# Python-Based Mobile Device Data Analysis

## Project Overview

This project analyzes mobile phone specifications using Python and descriptive statistics to identify the most suitable devices based on technical specifications and budget requirements.

## Business Problem

A client wanted to compare multiple smartphone models objectively rather than relying on subjective reviews. The goal was to identify the best options using statistical analysis.

## Technologies

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Dataset

- 50 Mobile Phone Models
- Technical Specifications
- Display
- Camera
- Battery
- RAM
- Storage
- Price

## Workflow

- Data Loading
- Data Cleaning
- Exploratory Data Analysis
- Descriptive Statistics
- Feature Comparison
- Device Evaluation
- Final Recommendation

## Results

- Analyzed 50 smartphone models
- Applied descriptive statistical techniques
- Recommended the top three smartphones based on predefined criteria
